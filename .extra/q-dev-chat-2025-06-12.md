## Service-Epitope Plugin

This is a T-cell epitope group matching service specifically for the HLA-DPB1 locus. The project provides functionality for matching donors and recipients based on their HLA-DPB1 epitope groups to determine transplant compatibility.

### Key Features:

1. **Epitope Matching**: The service evaluates the compatibility between donor and recipient HLA-DPB1 alleles based on T-cell epitope groups.

2. **Match Grading**: It categorizes matches into different grades:
   - MATCH
   - PERMISSIVE
   - POTENTIAL
   - GVH_NONPERMISSIVE (Graft versus Host nonpermissive)
   - HVG_NONPERMISSIVE (Host versus Graft nonpermissive)
   - NONPERMISSIVE_UNDEFINED
   - UNKNOWN

3. **Race/Ethnicity Consideration**: The service takes into account the race/ethnicity of both donor and recipient when calculating match probabilities.

4. **REST API**: Implemented as a Dropwizard service with RESTful endpoints for querying match information.

5. **Command-line Tools**: Includes command-line utilities for:
   - `epitope-alleles`: Working with HLA alleles
   - `epitope-groups`: Working with epitope groups
   - `epitope-matches`: Performing epitope matching

### Architecture:

The project is organized as a multi-module Maven project with the following components:

- **client**: Client library for accessing the service
- **db**: Database management and migrations
- **domain**: Core domain models
- **dropwizard**: REST API service implementation
- **fitnesse**: Acceptance testing framework
- **resource**: API resource definitions
- **resource-impl**: Implementation of API resources
- **service**: Core service logic
- **tools**: Command-line tools

### Technical Stack:

- Java 8
- Maven for build management
- Dropwizard for REST API framework
- SQLite for database
- Flyway for database migrations
- Google Guice for dependency injection
- FitNesse for acceptance testing

This service is particularly useful in the field of hematopoietic stem cell transplantation, where matching HLA-DPB1 epitopes between donors and recipients can help predict transplant outcomes and reduce complications like graft-versus-host disease.
